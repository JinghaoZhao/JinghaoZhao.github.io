# Anthropic 的算力支出已接近每季度100亿美元：大模型竞争正在变成怎样一门生意？

2026年11月18日，独立研究机构 Epoch AI 的研究员 Josh You 发表了[《Anthropic’s compute spending is increasing by 4x per year, outpacing OpenAI’s 3x》](https://epoch.ai/data-insights/anthropic-openai-compute-spend-growth)，全文及配套数据免费开放，结合图表与方法说明适合花约十分钟精读。Anthropic 的上市申报材料首次提供了连续七个季度的算力与基础设施开支，使外界能够把模型研发的投入规模、客户推理的成本和云服务商的收入放到同一框架下理解。本文依据该研究（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）重新组织中文叙事，并核对其引用的[Anthropic 11月2日修订版 S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)。以下金额均为美元。

## 季度账单已经接近百亿美元

2023年，Anthropic 一整年的算力与基础设施费用只有4.33亿美元。2024年，这个数字变成25.22亿美元，2025年达到73.26亿美元。而到了2026年第三季度，公司仅用三个月就产生了98.63亿美元的相关费用，超过2025年全年的支出。

为了把年度数据与季度数据放在同一张曲线上，Epoch 将季度费用乘以四，得到年化支出速率。这里的年化是一个标准化的比较口径，表示如果当季水平保持一年会产生多少费用，并不是对2026年实际全年支出的预测。

| 期间 | 实际算力及基础设施费用（亿美元） | 年化速率（亿美元） |
| --- | ---: | ---: |
| 2023全年 | 4.33 | 4.33 |
| 2024全年 | 25.22 | 25.22 |
| 2025年第一季度 | 9.44 | 37.76 |
| 2025年第二季度 | 13.90 | 55.60 |
| 2025年第三季度 | 20.47 | 81.88 |
| 2025年第四季度 | 29.45 | 117.80 |
| 2026年第一季度 | 33.87 | 135.48 |
| 2026年第二季度 | 55.58 | 222.32 |
| 2026年第三季度 | 98.63 | 394.52 |

数据来源：[Epoch AI 配套数据表](https://epoch.ai/data-insights/anthropic-openai-compute-spend-growth)及[S-1/A](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)。表中年化值根据实际季度金额计算，未作通胀调整。

曲线的斜率比最后一个数字本身更值得研究。从2025年第三季度到2026年第三季度，Anthropic 的季度支出增长到约4.82倍；但这不等于整个观测期的趋势增速。用2023年至2026年第三季度的全部观测值拟合，Epoch 得到约每年4倍的增长趋势，90%置信区间为3.6至4.5倍。按拟合中心值计算，费用大致每半年翻番。个别季度的实际变化有快有慢，不能把拟合结果当成未来每个季度必然发生的变化。

## OpenAI 的历史投入更大，但增长率比较没有那么确定

OpenAI 没有在这项研究中提供与 Anthropic 招股书同等连续、同等口径的财务披露。研究团队只能从公开报道还原其历史算力支出。其中，2022年的4.16亿美元还包括部分数据费用，2024年的58亿美元来自当时媒体披露的预测，包含18亿美元推理费用和40亿美元研发算力费用；2025年的报道数字是163亿美元，其中客户推理约80亿美元，研发算力约83亿美元。

2026年的数字尤其需要与历史数据分开。OpenAI 总裁 Greg Brockman 在2026年5月作证时曾表示，公司预计当年投入约500亿美元用于计算资源，[路透社报道了这项预测](https://www.reuters.com/technology/openai-projects-50-billion-spending-computing-power-this-year-brockman-says-2026-05-05/)。Epoch 在11月18日发布研究时仍没有取得 OpenAI 2026年的非预测性开支数字。因此，图上500亿美元的点是计划，不是已经花出去的钱。

使用现有历史数据，OpenAI 的拟合中心值约为每年3.5倍，90%置信区间约为2至5倍。文章标题使用约3倍来描述其增长量级。由于观测点较少、部分数据来自预测和媒体报道，OpenAI 的估计范围明显宽于 Anthropic。两家的区间存在重叠，不能仅凭这条拟合曲线断定 Anthropic 的真实增长率已经在统计意义上超过 OpenAI，更不能从 Anthropic 的第三季度年化速率与 OpenAI 的全年预算直接推断两家当年的实际支出差距。

## 如何从几份财务报表还原一条指数曲线

公司披露的费用是某段时期内累计发生的金额，而不是某天的瞬时支出。假设算力开支在一个季度内不断增加，那么季度平均水平通常对应于接近季度中间的某个时点；如果使用全年累计数字，观测时点也并不等于12月31日。

Epoch 假设相邻报告期之间的支出沿平稳指数趋势增长，推算各期平均速率对应的日期。季度数据在季度中点后约1至3天，年度数据在年中之后约2至4周。以这些时点及其年化速率建立对数线性回归，就可以从拟合斜率得到年增长倍数，而不是简单地计算第一笔与最后一笔金额的比例。研究人员通过回归标准误给出90%置信区间，并额外考察日期估计的不确定性，发现后者对区间的影响较小。[原文提供了方法说明和分析代码链接](https://epoch.ai/data-insights/anthropic-openai-compute-spend-growth)。

这种统计处理解决的是不同报告周期的对比问题，并不能消除原始数据本身的缺陷。Anthropic 的财务报表与 OpenAI 的媒体估计有不同的可靠程度；公司计算资源的购置方式也可能变化。拟合区间主要反映模型中的估计不确定性，不能自动覆盖媒体报道遗漏、会计定义变动或未来商业环境改变等风险。

## 算力不只是回答用户问题，更大的部分还在内部消耗

模型公司使用计算资源有两类主要目的：一类是向客户提供推理服务，即让训练完成的模型处理外部请求；另一类是内部研发，包括新模型的训练、实验、评估及其他内部使用。区分这两部分，可以理解为什么算力支出增长得很快，却不能简单拿它除以订阅收入来计算每位用户的服务成本。

Anthropic 的招股书同时提供了按费用性质与按业务功能呈现的数据。算力与基础设施费用横跨多种业务功能；收入成本（cost of revenue）则几乎全部来自客户服务所需的算力和基础设施，也包含少量人员及分摊开支。因此 Epoch 采用收入成本近似估算商业推理支出，而不是将其视为准确的物理算力用量。

2025年，Anthropic 的总算力与基础设施费用为73.26亿美元，收入成本为27.73亿美元，两者之比约38%。2026年前九个月，总算力与基础设施费用增至188.08亿美元，收入成本为48.12亿美元，两者之比降至约26%。这并不意味着商业推理的绝对支出减少了，而是内部及其他用途的算力开支扩张得更快。

其中还有一处会计边界。免费用户的推理费用记入销售与营销，而不计入收入成本，所以收入成本可能略低估全部对外推理开支。不过，2026年前九个月 Epoch 所引用的销售和营销费用约55亿美元，同比增加约52亿美元，其中48亿美元来自向云合作伙伴支付的收入分成费用。由此判断，免费层算力并不是这笔营销费用的主要来源，其量级至多为数亿美元。加上这部分也不太可能逆转内部算力开支占多数的结论。

相比之下，Epoch 汇总的媒体报道显示，OpenAI 在2025年约有一半的算力支出用于客户推理，而2024年这一比例约为三分之一。两家公司的收入构成、产品和模型组合可能不同，不能用这一比值直接评价研发效率或模型质量。

## 钱最终流向哪些基础设施公司？

目前两家公司主要依靠外部云计算与算力合作伙伴，而不是由模型公司自己承担全部服务器、电力和数据中心建设成本。Amazon、CoreWeave、Google、Microsoft、Oracle 和 SpaceX 都属于这一供应体系中的参与者。不过，两家模型公司的完整供应商开支分布没有公开，不能把这个名单理解为每一家均向两家公司提供了相同份额的资源。

SpaceX 是一个可以从外部收入数据观察的大规模例子。Epoch 援引报道估算，2026年第三季度 Anthropic 贡献了 SpaceX 总收入的34.5%，相当于约50亿美元。这与 Anthropic 当季98.63亿美元的算力与基础设施费用相比，约为一半。该比例来自供应商收入报道与客户费用披露的对照，而非 Anthropic 逐项公布的采购账单。它揭示了供应商一侧可能出现的收入集中，但不等同于精确的现金付款时点。

费用增长与采购方式有关。Anthropic 正在传统云租用之外增加直接租赁芯片、委托专用设施托管的 Anthropic Direct 模式，未来包括更多直接租赁的 TPU。租赁支出仍会按适用会计方式在使用期间确认，因此历史费用序列比直接将一次性的设备资本开支与云租金混合比较更有意义；随着自有设备、租赁与预付款占比上升，现金流和费用确认的差异也需要持续关注。相关背景见[Epoch AI 此前对 Anthropic 融资与算力的研究](https://epoch.ai/gradient-updates/will-financing-bottleneck-ai-compute)及[公司招股书](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)。

## 四倍增长与已经签下的长期承诺不是一回事

截至2026年9月30日及之后签订的采购承诺与租赁协议中，Anthropic 有约4475亿美元预计在2030年底前发生，绝大部分对应计算和基础设施。把这笔金额摊到2026年剩余时间至2030年底，得到每年约1000亿美元的量级。它大致是第三季度年化速率的两倍多，而不是在今后四年继续每年增长到前一年的四倍。OpenAI 据报道在相近期间计划投入约7500亿美元；这是一项计划，也并非同样口径的已签约义务。

Anthropic 仍可能在现有合同之外追加采购，未来实际费用也会随供给交付、融资与需求变化而调整。4475亿美元是披露的承诺规模，而不是未来支出的上限或某一年的费用。Epoch 的历史回归不能直接外推至2030年；那将隐含远超当前已承诺采购金额的开支路径。

还有一个常被忽略的转换问题：美元开支不是算力的物理单位。不同芯片具有不同的运算吞吐、内存容量和能效，租赁协议条款与单位算力价格也会变化。即使某家模型公司的美元开支增加四倍，也不能由此断定其 GPU 数量、电力需求、FLOPS（浮点运算能力）或可完成的推理任务数量同时增加四倍。两家公司的账单还包含配套 CPU 与其他通用云基础设施，细分到加速器的比例并未完整披露。这些都是[原研究](https://epoch.ai/data-insights/anthropic-openai-compute-spend-growth)明确保留的测量限制。

## 延伸判断与启示

最有价值的观察不是谁在某个季度花的钱更多，而是算力费用、合同承诺和客户收入之间的时间差。模型厂商在需求完全确定以前就得锁定未来数年的资源，这使得 AI 行业既具有软件产品扩张速度快的一面，又带有重资产基础设施的合同约束。Anthropic 的[修订版 S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)同时披露，2026年前九个月算力与基础设施费用占收入的57%，较上年同期172%明显下降；它也披露了同一期间65亿美元的短期算力承诺相关费用，短期资源成本高于可比长期采购。两件事可以同时成立：高速增长的商业收入有机会改善规模经济，但供应不足时仍要支付溢价，而采购过多时又会承受利用率和现金流压力。真正值得跟踪的是长期容量交付后能否替代昂贵的短期算力，以及新增收入能否持续覆盖新增的固定承诺，而不是仅凭模型使用量或总支出增速推断盈利。

对云计算、半导体及数据中心投资而言，模型公司的账单既是基础设施需求的证据，也提醒我们区分三条曲线：计算资源已经交付并产生的收入，客户未来合同约定的购买量，以及供应商自己的资本开支和融资成本。三者不会同步变化。即使模型厂商的历史费用增长放缓，只要仍有大量已签容量等待交付，部分基础设施供应商的收入仍可能增长；反之，如果采购价格下降、订单取消条件被触发或新增设备利用率不足，巨额合同也未必能转化为同等规模的利润。衡量未来投资机会，应优先检验实际交付、客户集中度、合同约束、单位算力价格及投入资本回报，而不是把历史四倍增速直接套用到估值模型里。
